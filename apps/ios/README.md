# Khaled AI iPhone App

The final client should be a native iPhone app with a professional UI.

Planned screens:
- Home / Assistant
- Chat
- People
- Messages
- Reminders
- Memory
- Voice
- Settings / Integrations

Planned Apple capabilities:
- App Intents
- notifications
- speech/voice APIs as appropriate
- supported Messages capabilities
- supported calling capabilities

The current PWA is a prototype, not the finished iPhone implementation.
